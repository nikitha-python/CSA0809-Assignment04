#CSA0809 - Python Programming

## About
This repository contains the code for Assignment 4. It covers file handling, exception handling, custom exceptions and program organisation through six small real-world tasks. Each task is a separate Python file.

## Programs

| No. | Topic | File | Concepts |
|-----|-------|------|----------|
| 1 | File Processing Design Review | `Task 1 – File Processing Design Review.py` | Reading files, with statement, try-except, rejected lines |
| 2 | Biometric Attendance File Processing | `Task 2 – Biometric Attendance File Processing.py` | Processing multiple files, dictionaries, attendance percentage |
| 3 | Exceptions in Attendance Processor | `Task 3 – Exceptions in Attendance Processor.py` | Custom exception, raise, FileNotFoundError |
| 4 | File and Exception Forensics | `Task 4 – File and Exception Forensics.py` | Writing and appending files, PermissionError, OSError |
| 5 | Python Program Organisation | `Task 5 – Python Program Organisation.py` | Functions, modules and package-style organisation |
| 6 | College Fest Registration Desk | `Task 6 – College Fest Registration Desk.py` | Validation, duplicate detection, error log, event-wise summary |

## How to Run
Python 3 is required. No external libraries are needed.

```
python "Task 1 – File Processing Design Review.py"
```

Replace the file name to run any other program.

Note: Tasks 1 and 4 create sample files while running (`/tmp/mess.txt`, `day1.txt` to `day3.txt` and `returns.log`).
